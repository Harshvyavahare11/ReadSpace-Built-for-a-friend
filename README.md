## 🌟 Overview

**ReadSpace** is built for book lovers who want a beautiful, distraction-free space to organize their library, track offline physical reading sessions, set daily reading goals, and capture life-changing quotes and personal reflections.

Developed for the **[Hacktoberfest Weekend Challenge: Build for a Friend](https://dev.to/challenges/hacktoberfest-weekend-2026-10-01)**.

- **Live Deployed Web App**: [https://harshvyavahare11.github.io/ReadSpace-Built-for-a-friend/](https://harshvyavahare11.github.io/ReadSpace-Built-for-a-friend/)
- **GitHub Repository**: [https://github.com/Harshvyavahare11/ReadSpace-Built-for-a-friend](https://github.com/Harshvyavahare11/ReadSpace-Built-for-a-friend)

## ✨ Features

1. **Dashboard**: Reading stats, streak counters, active focus book card, 2026 reading challenge, target finish countdowns, and recent log timeline.
2. **My Library**: Shelf organization (*Currently Reading*, *Want to Read*, *Completed*, *On Hold*) with live search, genre/format filters, sorting, and seamless Grid/List view toggling.
3. **Reading Velocity Tracker**: Calculates required daily reading pace (*"Read 24 pages/day to finish on schedule!"*).
4. **My Notes & Quotes**: Centralized journal with serif quote cards, tag management, and one-click copy-to-clipboard.
5. **Physical Book Mode**: Distraction-free offline reading stopwatch timer and physical ribbon bookmark page synchronizer.
6. **Discover Catalog**: Curated sample book catalog with category filters and custom shelf placement.
7. **Settings & LocalStorage**: Theme switcher (Warm Off-White Library vs Deep Dark Mode), JSON data backup export, and sample data reset.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/Harshvyavahare11/ReadSpace-Built-for-a-friend.git
cd ReadSpace-Built-for-a-friend
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:5173/](http://localhost:5173/) in your browser.
